# HexDreams IRC 0.27.0 — Windows portable

- Scripts: listado compacto con columnas Script, Activar, Editar, Ayuda y Eliminar. Editar abre el script seleccionado.
- Colores de texto: paleta IRC de 16 colores para identidad, nick completion, NOTICE, /me y resaltado. Los selectores del tema conservan sus colores libres.

Extrae todo el ZIP y ejecuta HexDreamsIRC.exe desde su carpeta. No requiere instalación.
